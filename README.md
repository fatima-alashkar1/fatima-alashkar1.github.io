# Fatima Alashkar — Portfolio

A static, GitHub Pages–ready portfolio for Fatima Mahmoud Alashkar.

## Edit it yourself

- `index.html` — all portfolio text, project descriptions, links, and certificate names
- `styles.css` — colors, spacing, typography, and responsive layout
- `certificates/` — the original certificate PDFs used in the portfolio
- `Fatima-Alashkar-CV.pdf` — the downloadable CV

Search for `href` in `index.html` to update links. Project cards currently use the project information from the CV; replace or add links when the repositories are public.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `fatima-alashkar.github.io`.
2. Upload `index.html`, `styles.css`, `README.md`, `Fatima-Alashkar-CV.pdf`, and the `certificates` folder.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
5. Save. GitHub will provide the public URL for your CV.

No build step or framework is required. Edit the files directly on GitHub and refresh the site after GitHub Pages redeploys.
